About This Repository

This repository contains 20 Java programs completed as part of the BCA201P – Foundations of Java Development Lab Assignment.

The programs demonstrate basic Java concepts such as classes, objects, instance variables, local variables, static variables, methods, conditions, and calculations.

The purpose of this lab is to understand and practice fundamental Java programming concepts through practical programs.
